URL PATTERNS
═════════════════════════════════════════════════════════════════════════════════

SHIFT FUEL REPORTS:
  Base URL: /reports/staff_shift_fuel_report.php
  Parameters:
    • shift={shift1|shift2|24hour}  (Required)
    • report_date=YYYY-MM-DD        (Optional, defaults to today)
  
  Examples:
    ✓ /reports/staff_shift_fuel_report.php?shift=shift1&report_date=2026-07-04
    ✓ /reports/staff_shift_fuel_report.php?shift=shift2
    ✓ /reports/staff_shift_fuel_report.php?shift=24hour&report_date=2026-07-08

MERCHANDISE/SERVICE REPORT:
  Base URL: /reports/staff_daily_merchandise_service_report.php
  Parameters:
    • report_date=YYYY-MM-DD        (Optional, defaults to today)
  
  Examples:
    ✓ /reports/staff_daily_merchandise_service_report.php?report_date=2026-07-04
    ✓ /reports/staff_daily_merchandise_service_report.php

INDEX PAGE:
  Base URL: /reports/daily_reports_index.php
  Parameters:
    • report_date=YYYY-MM-DD        (Optional, defaults to today)
  
  Example:
    ✓ /reports/daily_reports_index.php?report_date=2026-07-04

ACCESS CONTROL FLOW
═════════════════════════════════════════════════════════════════════════════════

User Request → Authentication Check → Role Check → Module Check → Report Display
     ↓                  ↓                  ↓             ↓              ↓
  Any User      Session Valid?    Authorized Role?  Module Enabled?   Show Report
                     ↓                  ↓                 ↓
                  ✓ Yes              ✓ Staff          ✓ Reports
                  ✗ No → Login      ✗ Guest → Deny    ✗ Disabled → Message

KEYBOARD SHORTCUTS (Future Enhancement):
  Ctrl+P          → Print current report
  Ctrl+Left/Right → Switch shift tabs
  Ctrl+T          → Jump to today's date

COMMON WORKFLOWS:

1. View Today's Shift 1 Report:
   Sidebar → Reports → Daily Reports → Shift 1 Fuel Sales

2. View Past Date Report:
   Index Page → Select Date → Click Report Card

3. Print Report for Manager:
   Open Report → Print Button → Save as PDF → Email

4. Compare Shifts:
   Open Shift 1 → Note totals → Click Shift 2 Tab → Compare

5. Export to Excel (Manual):
   Open Report → Print → Save as PDF → Convert PDF to Excel online
