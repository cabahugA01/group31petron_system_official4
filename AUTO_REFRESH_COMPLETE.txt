HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

1. Page loads → Timer starts (60 seconds)

2. After 60 seconds → autoRefresh() function is called

3. Function checks: Is a modal currently open?
   
   YES → Skip refresh, wait for next cycle
   NO  → Proceed to refresh

4. If refreshing:
   - Capture all current URL parameters (filters, search, dates)
   - Build reload URL with preserved parameters
   - Add timestamp to bypass cache
   - Use window.location.replace() for silent reload

5. Timer automatically restarts after refresh

═══════════════════════════════════════════════════════════════════════════
MODAL TRACKING LOGIC
═══════════════════════════════════════════════════════════════════════════

OPENING A MODAL:
- User clicks: Adjust, Correct, or Void button
- Wrapper function intercepts the call
- Sets: isModalOpen = true
- Opens the modal normally
- Auto-refresh is now PAUSED

CLOSING A MODAL:
- User clicks: Close button or overlay
- Wrapper function intercepts the call
- Sets: isModalOpen = false
- Closes the modal normally
- Auto-refresh RESUMES

═══════════════════════════════════════════════════════════════════════════
CONFIGURATION
═══════════════════════════════════════════════════════════════════════════

To change refresh interval, modify this line:
setInterval(autoRefreshManagerMonitoring, 60000);
                                          ^^^^^^
                                          milliseconds

Common intervals:
- 30000  = 30 seconds (more frequent)
- 60000  = 60 seconds (current default)
- 120000 = 2 minutes
- 300000 = 5 minutes

To disable auto-refresh, comment out:
// window.refreshManagerMonitoringTimer = setInterval(...);

SUPPORT & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

ISSUE: Page not refreshing
CHECK:
- Browser console for JavaScript errors
- Timer variable is defined (window.refreshManagerMonitoringTimer)
- Function autoRefreshManagerMonitoring() exists
- No syntax errors in JavaScript

ISSUE: Filters not persisting
CHECK:
- Form uses method="GET" (not POST)
- Input fields have correct "name" attributes
- URL parameters are being captured correctly

ISSUE: Modal doesn't pause refresh
CHECK:
- Wrapper functions are defined
- isManagerModalOpen variable is toggling
- Wrapper functions call original functions correctly
- Modal functions are defined before wrappers

ISSUE: Refresh happening too often
CHECK:
- Only one timer is running (not multiple)
- Clear old timers before setting new ones
- Check setInterval millisecond value
