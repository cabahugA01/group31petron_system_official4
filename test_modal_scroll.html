Troubleshooting Checklist:

  1. Modal won't scroll? Check if .mi-body has overflow-y:auto and flex:1
  2. Header scrolling with content? Ensure .mi-head has flex-shrink:0
  3. Footer scrolling with content? Ensure .mi-foot has flex-shrink:0
  4. Content cut off? Check .mi-box has overflow:hidden not overflow-y:auto
  5. Not working on mobile? Add -webkit-overflow-scrolling:touch to .mi-body

Technical Details:

  • Layout: Flexbox with flex-direction:column
  • Scrolling: Only .mi-body with overflow-y:auto
  • Fixed elements: .mi-head and .mi-foot with flex-shrink:0
  • Height control: max-height:calc(100vh - 60px) on .mi-box
  • Mobile optimization: Touch scrolling and responsive padding
