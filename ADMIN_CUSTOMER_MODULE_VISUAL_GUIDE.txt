══════════════════════════════════════════════════════════════════════════════
                         ACCESS & PERMISSIONS
══════════════════════════════════════════════════════════════════════════════

✅ ALLOWED:
  • View all customers
  • Search & filter customers
  • View customer profiles
  • View transaction history
  • View documents (Gov ID, CR)
  • Download documents
  • Export reports (PDF/Excel/CSV)
  • Print profiles

❌ NOT ALLOWED:
  • Add new customers
  • Edit customer information
  • Delete customers
  • Modify transactions
  • Change customer status
  • Verify customers
  • Archive/restore customers

══════════════════════════════════════════════════════════════════════════════
                              QUICK TIPS
══════════════════════════════════════════════════════════════════════════════

1. Use filters to narrow down large customer lists
2. Export before applying filters if you want all customers
3. Transaction history is paginated - adjust rows per page for efficiency
4. Document access is logged automatically for audit trail
5. Print function auto-opens print dialog
6. All exports respect active filters
7. Station scope is automatically enforced
8. Last transaction date includes all modules (Fuel, Merchandise, Job Orders)
