                        TROUBLESHOOTING CHECKLIST
═══════════════════════════════════════════════════════════════════════════════

SYMPTOM: Summary cards show "0"
CAUSE: Walay customers sa database OR wrong station_id
FIX: 
   □ Check customers table in phpMyAdmin
   □ Verify station_id sa user session
   □ Insert sample data kung empty

──────────────────────────────────────────────────────────────────────────────

SYMPTOM: Table shows "No customers found"
CAUSE: Filters nag-exclude sa tanan OR walay match sa search
FIX:
   □ Click "Reset" button to clear filters
   □ Check if station_id is correct
   □ Verify customers.station_id matches user's station

──────────────────────────────────────────────────────────────────────────────

SYMPTOM: JavaScript console error
CAUSE: API error OR database connection issue
FIX:
   □ Check browser console (F12)
   □ Test API directly: admin_customer_operations.php?action=list
   □ Check PHP error logs

──────────────────────────────────────────────────────────────────────────────

SYMPTOM: "Unauthorized access"
CAUSE: User role is not Admin/SuperAdmin/Developer
FIX:
   □ Verify user role in database
   □ Check roles table for correct permissions
   □ Ensure user is logged in as Admin
