                    🔍 UNSAY NAHITABO?
═══════════════════════════════════════════════════════════════════════════════

MEMORY Engine:
- Fast pero temporary
- Mawala ang data pag restart sa Apache/MySQL
- DILI dapat gamiton sa production

InnoDB Engine:
- Permanent storage
- Data ma-preserve even after restart
- SAKTO kini para sa production

Ang nahitabo:
1. Imong database gi-import with ENGINE=MEMORY
2. Nag-restart ang XAMPP/Apache
3. Nawala tanan tables kay MEMORY engine
4. Login dili mo-work kay wala na ang users table

Solution:
- Convert all tables to InnoDB
- NEVER use MEMORY engine sa production

═══════════════════════════════════════════════════════════════════════════════
                    📋 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: After import, MEMORY pa gihapon
FIX:
   1. Open ang backup file sa text editor
   2. Find: ENGINE=MEMORY
   3. Replace with: ENGINE=InnoDB
   4. Save
   5. Re-import

────────────────────────────────────────────────────────────────────────────────

PROBLEM: Import fail - "Max execution time"
FIX:
   1. Edit: c:\xampp\php\php.ini
   2. Find: max_execution_time = 30
   3. Change: max_execution_time = 300
   4. Find: upload_max_filesize = 2M
   5. Change: upload_max_filesize = 128M
   6. Restart Apache
   7. Try import again

────────────────────────────────────────────────────────────────────────────────

PROBLEM: "Table doesn't exist"
FIX:
   1. Tables nawala na (MEMORY engine cleared)
   2. Restore from backup file
   3. Run FIX_DATABASE_ENGINE.sql
   4. Test login
