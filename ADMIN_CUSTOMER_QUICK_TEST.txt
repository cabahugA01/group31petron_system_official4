STEP 1: CHECK IF DATA EXISTS (30 seconds)
────────────────────────────────────────────────────────────────────────────────
1. Open: http://localhost/phpmyadmin
2. Select: your database (petron_db or similar)
3. Click: SQL tab
4. Run:
   SELECT COUNT(*) FROM customers;

RESULT A: Shows 0
   → Walay customers sa database yet
   → Go to STEP 2 to insert sample data

RESULT B: Shows number > 0
   → Naa nay customers!
   → Skip to STEP 3 to test module

────────────────────────────────────────────────────────────────────────────────

STEP 2: INSERT SAMPLE DATA (IF NEEDED) (1 minute)
────────────────────────────────────────────────────────────────────────────────
1. Open file: CHECK_CUSTOMER_DATA.sql
2. Find these lines (around line 35-45):
   
   INSERT INTO customers (station_id, customer_id, ...)
   VALUES (1, 'C-001', ...);
   
3. IMPORTANT - CHANGE THESE:
   - station_id: 1  →  (your actual station ID)
   - registered_by: 1  →  (your actual user ID)

4. Copy ALL INSERT statements
5. Paste sa phpMyAdmin SQL tab
6. Click "Go" button
7. Check result: Should say "8 rows inserted"

────────────────────────────────────────────────────────────────────────────────

STEP 3: TEST THE MODULE (1 minute)
────────────────────────────────────────────────────────────────────────────────
1. Login as Admin user
2. Go to: Customers menu (sidebar)
3. Page loads → Check these:

   ✅ SUMMARY CARDS (Top of page)
      → Should show numbers (not all zeros if data exists)

   ✅ CUSTOMER TABLE
      → Shows customer rows (if data exists)

      → Each row has View 👁 and Print 🖨 buttons

4. Click "View" button on any customer
   → Profile overlay opens
   → Customer info displays

   → Transaction history table loads
   → Can filter history

5. Try filters:
   → Type sa search box

═══════════════════════════════════════════════════════════════════════════════
                    🔍 TROUBLESHOOTING QUICK FIXES
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: Summary cards all show "0"
FIX:
   □ Check database: SELECT COUNT(*) FROM customers;
   □ If 0, insert sample data (see STEP 2 above)
   □ If > 0, check station_id matches your user's station
   □ Hard refresh page: Ctrl + Shift + R

────────────────────────────────────────────────────────────────────────────────

PROBLEM: Table says "No customers found"
FIX:
   □ Click "Reset" button to clear all filters
   □ Check if customers.station_id matches your user's station
   □ Check customers.status (table may be filtering inactive)
   □ Verify in database: SELECT * FROM customers WHERE station_id = 1;

────────────────────────────────────────────────────────────────────────────────

PROBLEM: "Unauthorized access" error
FIX:
   □ Check your user role in database
   □ Should be: admin, superadmin, or developer
   □ Query: SELECT role FROM users WHERE id = YOUR_USER_ID;
   □ Update: UPDATE users SET role = 'admin' WHERE id = YOUR_ID;

────────────────────────────────────────────────────────────────────────────────

PROBLEM: JavaScript console errors
FIX:
   □ Open browser console (F12)
   □ Look for red errors
   □ Common issue: 404 on admin_customer_operations.php
      → Check file exists in public/ folder
      → Check file permissions (should be readable)
   □ Network error:
      → Check Apache is running
      → Check MySQL is running

────────────────────────────────────────────────────────────────────────────────

PROBLEM: Profile overlay doesn't open
FIX:
   □ Open browser console (F12)
   □ Click View button
   □ Check for JavaScript errors
   □ Test API directly:
      → Go to: admin_customer_operations.php?action=view&id=1
      → Should return JSON with customer data
