═══════════════════════════════════════════════════════════════════════════
NAVIGATION FLOW
═══════════════════════════════════════════════════════════════════════════

CREATING NEW TRANSACTIONS:
Staff clicks: Transactions → New Transaction
             → Opens transactions hub
             → Choose: Merchandise | Job Order | Fuel tabs
             → Create transaction
             → Save and print receipt

VIEWING TRANSACTION HISTORY:
Staff clicks: Transactions → Transaction History
             → Shows all encoded transactions
             → Filter by date, type, status
             → View details or print receipts

TRACKING JOB ORDERS:
Staff clicks: Transactions → Job Order Tracker
             → View all active service requests
             → See assigned technicians
             → Monitor completion status
             → Update progress

CHECKING MERCHANDISE HISTORY:
Staff clicks: Transactions → Merchandise History
             → View all merchandise sales
             → Check released items
             → Track product transactions
             → Generate reports

MANAGING RECEIPTS:
Staff clicks: Transactions → Receipts
             → Search for transactions
             → View receipt details
             → Reprint receipts
             → Email receipts (if enabled)
