# Admin Management - Quick Reference Guide 🚀

## Access the Module

**URL:** `http://your-domain/group31petron_system_official4/public/superadmin_admin_management.php`

**Required Role:** Developer or SuperAdmin

---

## Create New Admin Account ➕

1. Click **"Create Admin Account"** button (top right)
2. Fill in the form:
   - **First Name:** Admin's first name (required)
   - **Last Name:** Admin's last name (required)
   - **Email Address:** Admin's email - this will be their login (required)
   - **Station Assignment:** Select from searchable dropdown (required)
3. Click **"Create Admin"**
4. System will:
   - Auto-generate a secure 10-character password
   - Send credentials to the admin's email
   - Add admin to the database
   - Enforce one-admin-per-station rule

**Email Sent to Admin:**
```
Subject: Your Petron Station Admin Account Credentials

Dear {First Name Last Name},

Your Admin account has been created for Petron Station Management System.

Station : {Station Name}
Email   : {admin@email.com}
Password: {AutoGeneratedPassword}

IMPORTANT: You are required to change your password upon first login.
```

---

## Edit Admin Account ✏️

1. Find the admin in the table
2. Click **"Edit"** button
3. Update fields:
   - **First Name:** Can be updated
   - **Last Name:** Can be updated
   - **Email Address:** READ-ONLY (locked after creation)
   - **Station Assignment:** Can be reassigned
   - **Account Status:** Active or Inactive
4. Click **"Save Changes"**

**Note:** Email cannot be changed after account creation for security reasons.

---

## Deactivate Admin Account 🚫

1. Find the active admin in the table
2. Click **"Deactivate"** button
3. Confirm in the modal
4. Result:
   - Admin cannot login anymore
   - Records preserved for compliance
   - Station temporarily has no active admin
   - Audit log entry created

---

## Activate Admin Account ✅

1. Find the inactive admin in the table
2. Click **"Activate"** button
3. Confirm in the modal
4. Result:
   - Admin can login again
   - Station oversight restored
   - Audit log entry created

## Search & Filter 🔍

### Search Box
Type to search across:
- First Name
- Last Name
- Email Address
- Station Name

**Example:** Type "maria" → shows all admins with first name, last name, email, or station containing "maria"

### Status Filter
- **All Status** - Show everyone
- **Active** - Show only active admins
- **Inactive** - Show only deactivated admins

### Station Filter
- Searchable dropdown
- Type station name to filter
- Shows only admins from selected station
- Click X to clear filter

## Rules & Validations ⚠️

### Create Admin Rules
- ✅ First name is required
- ✅ Last name is required
- ✅ Email must be valid format (user@domain.com)
- ✅ Email must be unique (not already in use)
- ✅ Station must be selected
- ✅ **One admin per station** - cannot create if station already has an admin
- ✅ Password is auto-generated (you cannot set it manually)

### Edit Admin Rules
- ✅ First name is required
- ✅ Last name is required
- ✅ Email **cannot be changed** (locked field)
- ✅ Station can be reassigned
- ✅ Status can be changed

### Email Validation
- Must contain @ symbol
- Must have domain extension (.com, .ph, etc.)
- Must be unique in the system

## Common Scenarios 💡

### Scenario 1: Create First Admin for New Station
1. Click "Create Admin Account"
2. Enter first name: "Juan"
3. Enter last name: "Dela Cruz"
4. Enter email: "juan.delacruz@petron.com"

1. Click "Deactivate" on the admin
2. Confirm in modal
3. ✅ Admin cannot login, records preserved
4. Later: Click "Activate" to restore access

### Scenario 5: Search for Specific Admin
1. Type in search box: "maria santos"
2. Table filters to show only matching admins
3. Clear search to show all again

## Troubleshooting 🔧

### "This station already has an Admin"
**Cause:** One-admin-per-station rule  
**Solution:** Deactivate or reassign existing admin first

### "Email address is already in use"
**Cause:** Another admin has this email  
**Solution:** Use a different email address

### "Invalid email address format"
**Cause:** Email missing @ or domain  
**Solution:** Enter valid email (e.g., user@domain.com)

### Admin not receiving credentials email
**Cause:** Email delivery issue  
**Solution:** 
1. Check email spam/junk folder
2. Verify SMTP settings in `config/email_config.php`
3. Manually share credentials with admin

### Cannot edit admin's email
**This is by design:** Email is the login credential and cannot be changed after account creation for security reasons.

## Security Features 🔒

1. **CSRF Protection** - All forms protected against cross-site attacks
2. **Password Hashing** - Passwords stored as bcrypt hash
3. **Audit Logging** - All actions logged with timestamp and user
4. **Email Lock** - Login email cannot be changed after creation
5. **One Admin Rule** - Prevents multiple admins per station
6. **Status Control** - Deactivated admins cannot login

## Audit Trail 📝

All actions are logged in `activity_logs` table:
- Create Admin - "SuperAdmin created admin..."
- Edit Admin - "SuperAdmin updated admin..."
- Deactivate Admin - "SuperAdmin deactivated admin..."
- Activate Admin - "SuperAdmin activated admin..."

Each log includes:
- Timestamp
- SuperAdmin who performed action
- Admin affected
- Station involved
- Status changes

## Best Practices 👍

### Do's ✅
- ✅ Use professional email addresses (admin@company.com)
- ✅ Use real first and last names
- ✅ Deactivate admins when they leave (don't delete)
- ✅ Reassign stations when admins transfer
- ✅ Review admin list regularly

### Don'ts ❌
- ❌ Don't create multiple admins per station
- ❌ Don't use personal emails (gmail, yahoo, etc.)
- ❌ Don't share admin credentials
- ❌ Don't manually set passwords (use auto-generate)
- ❌ Don't delete admin records (deactivate instead)
