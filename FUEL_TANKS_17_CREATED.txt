-----------
Station 1 had NO fuel pumps in the database!
- fuel_inventory table had 5 fuel types (Diesel, Kerosene, Turbo Diesel, XCS, Xtra Advance)
- fuel_pumps table had 0 pumps for Station 1
- The code creates 1 default row per fuel type when no pumps exist
- Result: Only 5 rows displayed instead of 17

TOTAL: 17 PUMPS ✓

HOW IT WORKS:
-------------
The staff_transactions_hub.php file:
1. Queries fuel_inventory to get fuel types for the station
2. For each fuel type, queries fuel_pumps to get all pumps for that fuel type
3. Creates one table row per pump
4. If no pumps exist for a fuel type, creates 1 default row

Now that pumps exist, each pump gets its own row in the fuel transaction form.
