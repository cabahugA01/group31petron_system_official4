═══════════════════════════════════════════════════════════════════════════════
 DATABASE STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

TABLE: fuel_price_history
- id (INT, AUTO_INCREMENT, PRIMARY KEY)
- fuel_id (INT, NOT NULL) - References fuel_inventory.id
- old_price (DECIMAL(10,2), NOT NULL)
- new_price (DECIMAL(10,2), NOT NULL)
- reason (VARCHAR(500)) - Why price was changed
- effective_date (DATE) - When price becomes effective
- updated_by (INT) - User who made the change
- created_at (TIMESTAMP) - When record was created

INDEXES:
- idx_fuel_id on fuel_id
- idx_created_at on created_at

 WORKFLOW EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

EDIT PRICE WORKFLOW:
1. Manager clicks "Edit Price" button
2. Modal opens with current info
3. Manager enters:
   - New Price: ₱65.00
   - Reason: "Petron Price Advisory"
   - Effective Date: June 27, 2026
4. Clicks "Update Price"
5. System:
   - Inserts record in fuel_price_history
   - Updates price in fuel_inventory
   - Logs activity
   - Shows success message
   - Reloads page

VIEW & ROLLBACK WORKFLOW:
1. Manager clicks "View" button
2. Fuel Details modal opens
3. Manager sees price history:
   - ₱63.90 → ₱64.35 (Petron Price Advisory) - June 27
4. Manager realizes mistake, clicks "Rollback"
5. Rollback modal opens showing:
   - Current: ₱64.35
   - Rollback To: ₱63.90
6. Manager enters reason: "Wrong advisory applied"
7. Clicks "Confirm Rollback"
8. System:
   - Inserts new history with "ROLLBACK:" prefix
   - Updates price back to ₱63.90
   - Logs activity
   - Shows success message
   - Reloads page
