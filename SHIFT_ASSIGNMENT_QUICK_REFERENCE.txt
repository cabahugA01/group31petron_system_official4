ADDING A STAFF MEMBER:

  1. Go to Admin → User Management
  2. Click [+ Add User]
  3. Fill in basic info:
     - Full Name: Juan Dela Cruz
     - Email: juan@email.com (will be username)
     - Role: Staff ← Important!
  
  4. Shift fields will appear:
     ┌──────────────────────────────────────┐
     │ Assigned Shift *                     │
     │ [Shift 1 ▼]                         │
     │                                      │
     │ Shift Start Time    Shift End Time  │
     │ [06:00]             [14:00]         │
     └──────────────────────────────────────┘
  
  5. Click [Create User]

───────────────────────────────────────────────────────────────────────────────

IMPORTANT RULES:

  ✓ Staff = MUST have assigned shift (Shift 1, 2, or 3)
  ✓ Manager = Automatically "All Shifts"
  ✓ Admin = Automatically "All Shifts"
  ✗ Cannot assign "All Shifts" to Staff

TROUBLESHOOTING:

  Q: Shift fields not showing when adding user?
  A: Make sure you selected "Staff" as the role.

  Q: Staff cannot create transactions?
  A: Check if staff has an assigned shift. Edit user and select shift.

  Q: How to change staff from Shift 1 to Shift 2?
  A: Edit the staff user and change "Assigned Shift" dropdown.
