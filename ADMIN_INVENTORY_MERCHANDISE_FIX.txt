ADMIN MERCHANDISE INVENTORY FIX
===============================
DATE: 2026-06-29
ISSUE: Admin merchandise inventory page showing "No merchandise inventory records matched your filters"

ROOT CAUSE:
-----------
The SQL query in admin_inventory_merchandise.php was trying to SELECT a column that doesn't exist:
- Query tried to select: COALESCE(si.variance, 0.00) AS variance
- But station_inventory table does NOT have a "variance" column
- This caused the entire query to fail silently (caught by try-catch)
- Empty query result → empty $all_items → empty $filtered_items → empty $sorted_filtered
- Empty $sorted_filtered caused the "no records" message to display

SOLUTION:
---------
Changed the query to use a hardcoded 0.00 for variance instead of trying to read from non-existent column:
- Changed: COALESCE(si.variance, 0.00) AS variance
- To: 0.00 AS variance

FILES FIXED:
------------
1. public/admin_inventory_merchandise.php
   - Fixed main inventory query (line ~253)
   - Fixed print view query (line ~69)

DATABASE SCHEMA REFERENCE:
--------------------------
station_inventory table columns:
- id, station_id, product_id, stock_level, cost, price, closing_stock, 
  closing_date, closing_shift, reorder_level, capacity, unit, status, last_updated
- NO variance column exists!
