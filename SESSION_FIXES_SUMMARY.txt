FIX #1: ADMIN MERCHANDISE INVENTORY

FIX #2: ADMIN STAFF OVERSIGHT
═══════════════════════════════════════════════════════════════
ISSUE: "No staff records found for this shift"
FILE: backend/api/admin_staff_oversight_api.php

ROOT CAUSE:
- Shift filter too restrictive
- Only matched exact shift assignments (e.g., "Shift 1")
- Users with "All Shifts" excluded from both tabs
- Example: Manager with "All Shifts" not showing anywhere

SOLUTION:
Updated shift filters to include:
- Specific shift (e.g., "Shift 1")
- OR "All Shifts"
- OR NULL/empty shift assignments

OLD FILTER (Shift 1):
  assigned_shift LIKE '%Shift 1%' OR assigned_shift = '1'

NEW FILTER (Shift 1):
  assigned_shift LIKE '%Shift 1%' 
  OR assigned_shift = '1'
  OR assigned_shift LIKE '%All Shifts%'
  OR assigned_shift IS NULL
  OR assigned_shift = ''

RESULT:
✓ Shift 1 tab: Shows Judy (Shift 1 staff) + Edgar (All Shifts manager)
✓ Shift 2 tab: Shows Edgar (All Shifts manager)
✓ Staff with "All Shifts" now appear in all shift tabs
