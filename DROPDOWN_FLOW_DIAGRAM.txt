┌─────────────────────────────────────────────────────────────────────────────┐
│                           1. PAGE LOAD SEQUENCE                             │
└─────────────────────────────────────────────────────────────────────────────┘

    Browser Opens Page
           ↓
    Load HTML + CSS
           ↓
    ┌──────────────────────────────────────┐
    │ Execute JavaScript:                  │
    │ (async function loadStations())      │
    └──────────────────────────────────────┘
           ↓
    Fetch API Call
    GET: backend/api/module_config_api.php?action=get_stations
           ↓
    ┌──────────────────────────────────────┐
    │ API Returns JSON:                    │
    │ {                                    │
    │   "ok": true,                        │
    │   "stations": [                      │
    │     { id: 1, name: "...", ... },     │
    │     ... (1413 total)                 │
    │   ]                                  │
    │ }                                    │
    └──────────────────────────────────────┘
           ↓
    Store in Memory
    allStations = data.stations
           ↓
    Console Log
    "✅ Loaded 1413 stations"
           ↓
    [READY FOR USER INTERACTION]


┌─────────────────────────────────────────────────────────────────────────────┐
│                      2. USER CLICKS INPUT (EMPTY STATE)                     │
└─────────────────────────────────────────────────────────────────────────────┘

    User clicks search input
           ↓
    Event: searchInput.addEventListener('click')
           ↓
    Call: showAllStations()
           ↓
    ┌──────────────────────────────────────┐
    │ Render ALL 1413 stations:            │
    │                                      │
    │ resultsDiv.innerHTML =               │
    │   allStations.map(station => `       │
    │     <div onclick="selectStation()">  │
    │       ${station.name}                │
    │       ${station.location}            │
    │       Region: ${station.region}      │
    │     </div>                           │
    │   `)                                 │
    └──────────────────────────────────────┘
           ↓
    dropdown.style.display = 'block'
           ↓
    ┌────────────────────────────────────────────────┐
    │ USER SEES DROPDOWN:                            │
    │ ┌────────────────────────────────────────────┐ │
    │ │ Petron Station 1                           │ │
    │ │ Manila Branch | Region: NCR                │ │
    │ ├────────────────────────────────────────────┤ │
    │ │ Petron Station 2                           │ │
    │ │ Quezon City Branch | Region: Luzon         │ │
    │ ├────────────────────────────────────────────┤ │
    │ │ ... (scroll to see all 1413)               │ │
    │ ├────────────────────────────────────────────┤ │
    │ │ Total: 1413 stations loaded                │ │
    │ └────────────────────────────────────────────┘ │
    └────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│                         3. USER TYPES TO FILTER                             │
└─────────────────────────────────────────────────────────────────────────────┘

    User types: "Manila"
           ↓
    Event: searchInput.addEventListener('input')
           ↓
    Get query: "Manila" (lowercase: "manila")
           ↓
    ┌──────────────────────────────────────┐
    │ Filter Logic:                        │
    │                                      │
    │ const filtered = allStations.filter( │
    │   station =>                         │
    │     name.includes("manila") ||       │
    │     location.includes("manila") ||   │
    │     region.includes("manila")        │
    │ )                                    │
    └──────────────────────────────────────┘
           ↓
    Result: 15 stations match
           ↓
    ┌──────────────────────────────────────┐
    │ Highlight Matches:                   │
    │                                      │
    │ highlightMatch(text, "manila")       │
    │   → Replace "manila" with            │
    │      <strong style="background:      │
    │        yellow;">manila</strong>      │
    └──────────────────────────────────────┘
           ↓
    Render filtered results
           ↓
    ┌────────────────────────────────────────────────┐
    │ USER SEES FILTERED DROPDOWN:                   │
    │ ┌────────────────────────────────────────────┐ │
    │ │ Petron Station Manila                      │ │
    │ │ Manila Branch | Region: NCR                │ │ ← "Manila" in yellow
    │ ├────────────────────────────────────────────┤ │
    │ │ Petron Station 5                           │ │
    │ │ Manila City | Region: NCR                  │ │ ← "Manila" in yellow
    │ ├────────────────────────────────────────────┤ │
    │ │ ... (all matches shown)                    │ │
    │ ├────────────────────────────────────────────┤ │
    │ │ Showing 15 matching stations               │ │
    │ └────────────────────────────────────────────┘ │
    └────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│                     4. USER DELETES TEXT (EMPTY AGAIN)                      │
└─────────────────────────────────────────────────────────────────────────────┘

    User deletes "Manila" → input is empty
           ↓
    Event: input event fires
           ↓
    query.length === 0
           ↓
    Call: showAllStations()
           ↓
    Render ALL 1413 stations again
           ↓
    [BACK TO STATE 2]


┌─────────────────────────────────────────────────────────────────────────────┐
│                         5. USER SELECTS STATION                             │
└─────────────────────────────────────────────────────────────────────────────┘

    User clicks station in dropdown
           ↓
    Event: onclick="selectStation(id, name)"
           ↓
    ┌──────────────────────────────────────┐
    │ Set Values:                          │
    │   activeStationId = id               │
    │   searchInput.value = name           │
    │   dropdown.style.display = 'none'    │
    └──────────────────────────────────────┘
           ↓
    Update Status Bar
    "Selected: [Station Name] | Region: [Region]"
           ↓
    Call: loadStationModules()
           ↓
    Fetch API Call
    GET: station_module_api.php?action=get_station_modules&station_id=X
           ↓
    ┌──────────────────────────────────────┐
    │ API Returns 8 Modules:               │
    │ [                                    │
    │   { module_key: "transactions", ... },│
    │   { module_key: "fuel_management", ...},│
    │   ... (8 total)                      │
    │ ]                                    │
    └──────────────────────────────────────┘
           ↓
    Render Module Table
           ↓
    ┌────────────────────────────────────────────────┐
    │ USER SEES MODULE TABLE:                        │
    │ ┌────────────────────────────────────────────┐ │
    │ │ Module          Status    Toggle  Configure│ │
    │ ├────────────────────────────────────────────┤ │
    │ │ Transactions    Enabled   [ON]    [Config] │ │
    │ │ Fuel Mgmt       Enabled   [ON]    [Config] │ │
    │ │ Job Orders      Disabled  [OFF]   [Config] │ │
    │ │ ... (8 total modules)                      │ │
    │ └────────────────────────────────────────────┘ │
    └────────────────────────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│                   6. USER TOGGLES MODULE ON/OFF                             │
└─────────────────────────────────────────────────────────────────────────────┘

    User clicks toggle switch for "Job Orders"
           ↓
    Event: onchange="toggleStationModule(key, checked)"
           ↓
    Confirm dialog
    "Are you sure you want to enable/disable this module?"
           ↓
    User clicks "OK"
           ↓
    POST API Call
    station_module_api.php
    {
      action: 'toggle_module',
      station_id: X,
      module_key: 'job_orders',
      enabled: 1
    }
           ↓
    API Updates Database
    UPDATE station_modules
    SET is_enabled = 1
    WHERE station_id = X AND module_key = 'job_orders'
           ↓
    ┌──────────────────────────────────────┐
    │ API Returns:                         │
    │ {                                    │
    │   "ok": true,                        │
    │   "message": "Module updated"        │
    │ }                                    │
    └──────────────────────────────────────┘
           ↓
    Show Toast Notification (top center)
    "✓ Module updated successfully"
           ↓
    [MODULE NOW ENABLED FOR THIS STATION]
           ↓
    CASCADE EFFECT:
    All users at this station now see
    "Job Orders" in their sidebar


┌─────────────────────────────────────────────────────────────────────────────┐
│                     7. USER CLICKS OUTSIDE DROPDOWN                         │
└─────────────────────────────────────────────────────────────────────────────┘

    User clicks anywhere outside input/dropdown
           ↓
    Event: document.addEventListener('click')
           ↓
    Check: Is click target inside input or dropdown?
           ↓
    NO → Close dropdown
           ↓
    dropdown.style.display = 'none'
           ↓
    [DROPDOWN HIDDEN]


┌─────────────────────────────────────────────────────────────────────────────┐
│                    8. USER CLICKS DROPDOWN ARROW                            │
└─────────────────────────────────────────────────────────────────────────────┘

    User clicks ▼ arrow icon
           ↓
    Event: dropdownArrow.addEventListener('click')
           ↓
    e.preventDefault()
    e.stopPropagation()
           ↓
    Check: Is dropdown visible?
           ↓
    YES → Hide dropdown
      dropdown.style.display = 'none'
           ↓
    NO → Show all stations
      showAllStations()
           ↓
    [TOGGLE BEHAVIOR]

║                            KEY FUNCTIONS SUMMARY                              ║
╚═══════════════════════════════════════════════════════════════════════════════╝

┌───────────────────────────────────────────────────────────────────────────────┐
│ Function               │ Purpose                                              │
├───────────────────────────────────────────────────────────────────────────────┤
│ loadStations()         │ Fetch all 1413 stations from API on page load       │
│ showAllStations()      │ Display all stations in dropdown (no filter)         │
│ input event handler    │ Filter stations as user types                        │
│ selectStation()        │ Set selected station and load modules                │

│ highlightMatch()       │ Add yellow background to matching text               │
│ escapeHtml()           │ Prevent XSS attacks in station names                 │
│ click outside handler  │ Close dropdown when clicking outside                 │
│ arrow click handler    │ Toggle dropdown visibility                           │
