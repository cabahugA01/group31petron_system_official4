═══════════════════════════════════════════════════════════════════════════════
  KEY FEATURES SUMMARY
═══════════════════════════════════════════════════════════════════════════════

🔗 LINKING
   - Dropdown shows all expected deliveries for current station
   - Format: "PO Number - Product Name (Expected Qty Unit)"
   - Optional - staff can skip and do manual entry

⚡ AUTO-FILL
   - Selects all PO details automatically
   - Fields: Supplier, Product, Category, Unit, Expected Qty
   - Saves staff typing time

⚠ VARIANCE DETECTION
   - Real-time comparison: Expected vs Actual
   - Triggers on quantity input change
   - Shows warning before submit
   - Tolerance: 0.001 (floating point safe)

🎯 SMART UPDATE
   - Updates existing PO record (not creates new)
   - Sets status based on variance:
     * No variance → Pending Verification
     * Variance → Discrepancy
   - Adds variance note to admin_notes
   - Removes from expected deliveries list

📊 DUAL MODE
   - Mode A: Linked (select from dropdown)
   - Mode B: Manual (traditional entry)
   - Both modes work simultaneously
   - Staff chooses which to use
