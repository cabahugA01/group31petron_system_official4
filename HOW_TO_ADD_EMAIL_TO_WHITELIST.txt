   HOW TO ADD AN EMAIL TO PASSWORD RESET WHITELIST (STEP BY STEP)
═══════════════════════════════════════════════════════════════════════

STEP 1: Open the Configuration File
────────────────────────────────────
📂 File Location: config/password_reset_whitelist.php

You can open it with:
- Notepad++
- VS Code
- Any text editor


STEP 2: Find the Whitelist Array
────────────────────────────────────
Look for this section in the file:

    $password_reset_whitelist = [
        'yyangcabahug@gmail.com',
        
        // Add more whitelisted emails below (one per line)
    ];


STEP 3: Add Your Email
────────────────────────────────────
Add a new line with your email inside the array:

    $password_reset_whitelist = [
        'yyangcabahug@gmail.com',
        'newuser@gmail.com',          ← ADD YOUR EMAIL HERE
        'admin@example.com',           ← OR HERE
    ];

⚠️ IMPORTANT:
- Make sure to add a comma after EACH email
- Keep the email inside single quotes: 'email@example.com'
- Last email can have or not have a comma


STEP 4: Save the File
────────────────────────────────────
💾 Save your changes (Ctrl + S)


STEP 5: Test It
────────────────────────────────────
Option A: Use Testing Tool
   Go to: http://localhost/group31petron_system_official4/backups/testing_mocking/test_whitelist.php
   
Option B: Test Directly
   Go to: http://localhost/group31petron_system_official4/public/forgot_password.php
   Enter the new email and click "Send OTP"

EXAMPLE: Adding Multiple Emails
═══════════════════════════════════════════════════════════════════════

BEFORE:
-------
$password_reset_whitelist = [
    'yyangcabahug@gmail.com',
];


AFTER (Multiple Emails Added):
-------------------------------
$password_reset_whitelist = [
    'yyangcabahug@gmail.com',
    'admin@example.com',
    'manager@example.com',
    'staff@example.com',
    'pepito@gmail.com',
];


═══════════════════════════════════════════════════════════════════════

REMOVING AN EMAIL FROM WHITELIST
═══════════════════════════════════════════════════════════════════════

Option 1: DELETE the line completely
-------------------------------------
BEFORE:
    $password_reset_whitelist = [
        'yyangcabahug@gmail.com',
        'olduser@gmail.com',          ← Want to remove this
        'newuser@gmail.com',
    ];

AFTER:
    $password_reset_whitelist = [
        'yyangcabahug@gmail.com',
        'newuser@gmail.com',
    ];


Option 2: COMMENT OUT the line (keeps it for later)
----------------------------------------------------
    $password_reset_whitelist = [
        'yyangcabahug@gmail.com',
        // 'olduser@gmail.com',         ← Commented out (disabled)
        'newuser@gmail.com',
    ];
