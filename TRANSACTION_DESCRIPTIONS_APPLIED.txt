HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

1. INITIAL PAGE LOAD (PHP)
   - When page loads, PHP checks which tab is active
   - Displays the appropriate description in the header
   - Uses $active_tab variable to determine text

2. TAB SWITCHING (JavaScript)
   - When user clicks a different tab
   - switchInnerTab() function is called
   - Updates the description text dynamically
   - No page reload required

3. SMOOTH TRANSITION
   - Description changes instantly
   - Professional, clean appearance
   - Helps users understand current context
