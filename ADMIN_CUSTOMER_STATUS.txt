RESULT B: If count > 0
   → Module will show actual counts in summary cards
   → Table will display customer rows
   → THIS CONFIRMS DATA IS FROM DATABASE

STEP 2: TEST LIVE DATA FETCH
────────────────────────────────────────────────────────────────────────────────
Open browser console (F12) → Go to Network tab → Load admin_customers.php

1. Watch for this request:
   admin_customer_operations.php?action=list

2. Click on it → Preview tab → Check response:
   {
     "success": true,
     "customers": [...],  ← This array comes from database query
     "stats": {
       "total_customers": X,
       "new_registered": Y,
       ...
     }
   }

3. If customers array is empty [] → No data in database
4. If customers array has objects → Data is being fetched correctly

STEP 3: VERIFY SUMMARY CARDS UPDATE FROM API
────────────────────────────────────────────────────────────────────────────────
Check JavaScript console → Type:

    fetch('admin_customer_operations.php?action=list')
      .then(r => r.json())
      .then(d => console.log(d.stats));

Expected output:
    {
      total_customers: 0,      ← From COUNT(*) query
      new_registered: 0,       ← From DATE(registered_at) = CURDATE()
      regular_customers: 0,    ← From WHERE customer_type = 'regular'
      fleet_accounts: 0,       ← From WHERE customer_type = 'fleet'
      active_customers: 0,     ← From WHERE status = 'active'
      inactive_customers: 0    ← From WHERE status IN ('inactive','suspended')
    }

These values are calculated LIVE from database, NOT pre-coded!
