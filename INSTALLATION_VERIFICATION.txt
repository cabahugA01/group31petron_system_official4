========================================
TROUBLESHOOTING
========================================

If page doesn't load:
1. Check Apache/MySQL are running in XAMPP
2. Verify database connection in /public/db_connect.php
3. Check PHP error logs in XAMPP

If no data shows:
1. Verify job_orders table exists in database
2. Check if user has station assignment
3. Ensure job orders exist for selected date
4. Check role permissions

If exports fail:
1. Check PHP output buffering settings
2. Verify file write permissions
3. Clear browser cache
