HOW TO ACCESS:
================================================================================
1. Login as Staff/Cashier/Manager
2. Go to sidebar: Reports
3. Click: Deliveries Reports
4. OR navigate to: staff_deliveries_report.php

Default View: Fuel Deliveries Tab
Default Period: Current Month

================================================================================
HOW TO USE:
================================================================================
1. Select date range (start and end)
2. Click "Apply" to filter
3. Scroll down to see both Fuel and Merchandise sections
4. Review delivery records in both tables
5. Check shift summaries for totals
6. Review remarks for any issues
7. Print or export as needed

NO NEED TO SWITCH TABS - everything is on one page!

================================================================================
DATA REQUIREMENTS:
================================================================================
Required Database Tables:
- fuel_deliveries (for fuel tab)
- merchandise_deliveries (for merchandise tab)

Optional Tables (for better display):
- suppliers (shows supplier names)
- fuel_types (shows fuel type names)
- products (shows product names)

If optional tables don't exist, system shows IDs instead.
