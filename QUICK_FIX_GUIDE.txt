PROBLEM: Buttons not showing on manager customer page

✅ CODE STATUS: Already updated and ready in the file!

════════════════════════════════════════════════════════════════
                    🔥 FASTEST FIX 🔥
════════════════════════════════════════════════════════════════

1️⃣  HARD REFRESH THE PAGE
   
   Windows: Ctrl + Shift + R
   
   This forces the browser to reload everything without using cache.
   
   ✓ Try this FIRST - fixes 90% of cases!

════════════════════════════════════════════════════════════════

2️⃣  IF #1 DOESN'T WORK → RESTART APACHE

   • Open XAMPP Control Panel
   • Click "Stop" on Apache
   • Wait 3 seconds
   • Click "Start" on Apache
   • Go back to browser and press Ctrl + Shift + R again

════════════════════════════════════════════════════════════════

3️⃣  IF #2 DOESN'T WORK → CHECK IF CODE LOADED

   • Right-click on page → "View Page Source"
   • Press Ctrl + F to search
   • Search for: CACHE BUSTER v2.0
   
   ✓ Found it? → Code is loaded, browser cache issue
   ✗ Not found? → Server not loading updated file

════════════════════════════════════════════════════════════════

4️⃣  IF #3 SHOWS CODE NOT LOADED → CLEAR PHP CACHE

   Create file: c:\xampp\htdocs\group31petron_system_official4\clear.php
   
   Add this code:
   <?php
   if (function_exists('opcache_reset')) {
       opcache_reset();
       echo "Cache cleared!";
   } else {
       echo "No cache to clear";
   }
   ?>
   
   Open: http://localhost/group31petron_system_official4/clear.php
   Then reload manager page with Ctrl + Shift + R
