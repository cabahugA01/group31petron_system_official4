# ADMIN - DAILY MERCHANDISE & SERVICE SALES REPORT

## 📋 Overview

This is a **comprehensive 24-Hour Oversight Report** specifically designed for **ADMIN** role users. This report is **DIFFERENT from the Manager report** and contains additional sections that managers do not have access to.

## 🎯 Purpose

The Admin Daily Merchandise & Service Sales Report provides complete oversight of all merchandise and service transactions, including:
- Detailed transaction listings
- Staff performance metrics
- Inventory movement tracking
- Payment breakdowns
- Audit summaries

## 📂 File Location

**Report File:** `public/reports/admin_daily_merchandise_service_report.php`  
**Main Page:** `public/admin_reports.php`

## 🔗 Access

Navigate to: **Admin Reports → Merchandise & Service Sales** tab

URL: `http://localhost/group31petron_system_official4/public/admin_reports.php?section=merchandise_service`

## 📊 Report Sections

### 1. MERCHANDISE SALES
- Receipt Number
- Customer Name
- Product Category
- Product Name
- Quantity
- Unit Price
- Total Amount
- Staff Encoder
- **Footer:** Total Merchandise Sales

### 2. JOB ORDER / SERVICE SALES
- JO Number
- Customer Name
- Vehicle Plate
- Service Type
- Labor Fee
- Parts Cost
- Total Amount
- Mechanic Name
- Staff Encoder
- **Footer:** Total Service Income

### 3. MERCHANDISE PRODUCTS USED AS JOB ORDER PARTS
*Source: Merchandise Inventory*
- JO Number
- Customer Name
- Product Name
- Category
- Quantity Used
- Unit Price
- Total Cost
- **Footer:** Total Parts Used & Total Parts Cost

### 4. PAYMENT BREAKDOWN
- Payment Method (Cash, GCash, Card, Charge Account)
- Number of Transactions
- Amount per Method

### 5. STAFF PERFORMANCE *(ADMIN ONLY)*
🔴 **This section is NOT in Manager reports**
- Staff Name
- Merchandise Transactions Count
- Job Orders Count
- Total Sales
- Total Collection

**Purpose:** Monitor individual staff productivity and sales performance

### 6. INVENTORY IMPACT SUMMARY *(ADMIN ONLY)*
🔴 **This section is NOT in Manager reports**
- Product Name
- Beginning Stock
- Quantity Sold
- Quantity Used in Job Orders
- Ending Stock

**Purpose:** Verify if inventory movement is correct and track stock accuracy

### 7. DAILY COLLECTION SUMMARY
- Merchandise Sales
- Labor Income
- Parts Sales
- **Gross Sales**
- Discounts (-)
- **Net Collection**

### 8. TRANSACTION AUDIT SUMMARY *(ADMIN ONLY)*
🔴 **This section is NOT in Manager reports**
- Total Merchandise Transactions
- Total Job Orders
- Cancelled Transactions
- Voided Transactions
- Refunded Transactions

**Purpose:** Auditing and compliance tracking

### Key Fields:

- Payment methods
- Validation status
- Stock movements

## 🐛 Troubleshooting

### Report Shows "Station ID not found"
- Ensure admin user has valid station assignment
- Check database users table for station_id field

### No Data Displayed
- Verify date range has transactions
- Check validation_status = 'Approved' for merchandise
- Check job_orders status IN ('Completed', 'Released', 'Verified')

### Export Not Working
- Verify xlsx.full.min.js library is loaded
- Check browser console for JavaScript errors
- Ensure tables have tbody content
