🔄 Auto-Refresh Workflow

Step 1: Timer Starts 60-second countdown begins when page loads
Step 2: Timer Triggers After 60 seconds, refresh function is called
Step 3: Modal Check System checks if user is working in a modal
Step 4a: Modal Open → Skip If modal is open, refresh is postponed
Step 4b: Modal Closed → Refresh If no modal open, page reloads with all filters intact
Step 5: Timer Restarts New 60-second countdown begins

💻 Technical Implementation

// State tracking let refreshTimer = null; let isModalOpen = false; // Auto-refresh function function autoRefresh() { // Check if modal is open if (isModalOpen) return; // Preserve URL parameters const urlParams = new URLSearchParams(window.location.search); const currentSearch = urlParams.toString(); const reloadUrl = currentSearch ? '?' + currentSearch : window.location.pathname; // Silent reload with cache bypass window.location.replace(reloadUrl + (currentSearch ? '&t=' : '?t=') + Date.now()); } // Wrap modal functions const originalCloseModal = window.closeModal; window.closeModal = function(id) { originalCloseModal(id); isModalOpen = false; // Resume auto-refresh }; // Start timer window.refreshTimer = setInterval(autoRefresh, 60000); console.log('✅ Auto-refresh enabled (60s interval)');

⚙️ Configuration Options

Adjust Refresh Interval

Change the refresh frequency by modifying the millisecond value:

// 30 seconds (more frequent) setInterval(autoRefresh, 30000); // 60 seconds (current default) setInterval(autoRefresh, 60000); // 2 minutes (less frequent) setInterval(autoRefresh, 120000); // 5 minutes (minimal polling) setInterval(autoRefresh, 300000);

Disable Auto-Refresh

To disable the feature, comment out the timer or clear it:

// Option 1: Comment out the timer // window.refreshTimer = setInterval(autoRefresh, 60000); // Option 2: Clear the timer programmatically clearInterval(window.refreshTimer);
